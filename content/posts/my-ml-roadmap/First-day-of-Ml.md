## 1. DSA: Time Complexity
**Why do we learn this?** We receive data from the user, and we need a meaningful way to arrange it. That’s why we use Data Structures (Arrays, Linked Lists, Trees, Graphs) and Algorithms (structured instructions to solve a problem).

**The Core Concept:** Time complexity measures how much time an algorithm takes to execute. If Algorithm A takes 10 seconds and Algorithm B takes 15 seconds, we choose A for fast data processing. We only care about the part of the code that scales and takes the most time (the 10 seconds overrides the 1 second).

**The Big O Order (Fastest to Slowest):**
*   `1` (Constant)
*   `log(log n)`
*   `log(n)` (Logarithmic)
*   `n` (Linear)
*   `n²`, `n³` (Quadratic, Cubic)
*   `2ⁿ` (Exponential - impossible for large N)

## 2. Machine Learning: The Core Concepts
I started the CampusX playlist. Here is the breakdown of the hierarchy and the main types of ML:

**The Hierarchy:**
*   **AI (Artificial Intelligence):** The broad concept of machines doing tasks without human intervention.
*   **ML (Machine Learning):** A subset of AI used to analyze, visualize, and forecast data.
*   **DL (Deep Learning):** A subset of ML that uses algorithms to mimic the human brain using neurons.
*   **Data Science:** Using all of the above skills to produce meaningful output from data.

**Supervised vs. Unsupervised Learning:**

*   **Supervised Learning:** The model learns from **labeled data** (input + correct answer). 
    *   **Regression:** Predicting a continuous number (e.g., House prices).
    *   **Classification:** Predicting a discrete category (e.g., Spam vs. Not Spam).
*   **Unsupervised Learning:** The model learns from **unlabeled data** (no answers provided). It finds hidden patterns on its own.
    *   **Clustering:** Grouping similar data (e.g., Customer segmentation).
    *   **Dimensionality Reduction:** Reducing features while keeping data (e.g., PCA).
    *   **Association:** Finding rules (e.g., "People who bought X also bought Y").
