## html 
HTML is the hypertext markup language. This is a language used to make the skeleton of the web and make raw webpage 

Structures Content: Organizes text, images, and videos into a readable layout for browsers.Uses Tags: Relies on elements enclosed in angle brackets (like <p> for paragraphs) to mark up content.Connects Pages: Implements "hypertext" links (<a> tags) to navigate between different pages and sites.Core Components: Not a Programming Language: HTML is a markup language; it defines structure rather than performing logical computations or dynamic behavior.Works with Others: Pairs with CSS for visual styling and JavaScript for page interactivity.Basic Structure: Starts with a <!DOCTYPE html> declaration, followed by <html>, <head> for metadata, and <body> for visible content
